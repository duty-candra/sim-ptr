# SIM-PTR (Prototipe)

Sistem informasi monitoring Pilar Titik Referensi (PTR). Seluruh komponen berjalan di GitHub:
halaman web (GitHub Pages) dan data terenkripsi (`data.enc.json`) di repositori ini.

- Login memakai nama pengguna dan kata sandi; data hanya dapat dibuka dengan kata sandi akun.
- Admin dapat mengubah data (memerlukan token GitHub dengan izin tulis); Pengguna hanya melihat.
