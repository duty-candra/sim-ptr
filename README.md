# SIM-PTR (Prototipe)

Sistem informasi monitoring Pilar Titik Referensi (PTR) — prototipe statis (satu berkas `index.html`).

- Seluruh titik PTR adalah **data contoh**.
- Login hanya tampilan; belum ada autentikasi sungguhan.
- Data pemeriksaan tersimpan di peramban pengguna (localStorage), tidak dibagikan antar pengguna.

## Menjalankan
Buka `index.html` di peramban dengan koneksi internet (peta dasar dimuat dari layanan online), atau publikasikan lewat GitHub Pages
(Settings → Pages → Deploy from a branch → `main` / `(root)`).
